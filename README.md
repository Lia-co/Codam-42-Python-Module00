# DESCRIPTION
This is the first Python module in 42 core curriculum. It is aimed at helping students to undrstand Python's core concepts through community garden scenarios. 
The function must be written in Python 3.10+, and follows the flake8 linter standards.

Authorized functions in this module are:
- print()
- input()
- int()
- range()
- defining helper functions for recursion

After finishing this module, differences between function and program, differrent data types, if condition usage, recursion and type hints should be well understood by students.
